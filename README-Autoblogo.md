# Autoblogo SI

Natywny dodatek do panelu dodatków Gargonem. Automatycznie zakłada wybrane błogosławieństwo po wygaśnięciu poprzedniego i po zakończeniu walki.

Plik dodatku na GitHub Pages:

`https://shadoxddl.github.io/autoblogo/Autoblogo.js`

## Publikacja

1. Wgraj `Autoblogo.js`, `Autoblogo-loader.user.js` i ten plik do głównego katalogu repozytorium `ShadoxDDL/autoblogo`.
2. W **Settings → Pages** wybierz **Deploy from a branch**, gałąź `main` oraz katalog `/(root)`.
3. Po publikacji zainstaluj `Autoblogo-loader.user.js` w Tampermonkey.

Interfejs dodatku używa natywnych komponentów Gargonem i pojawia się w panelu dodatków.
